# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Job seekers in any field (Ireland/EU by default), many of them non-technical, on Windows or Mac.
They run their search from a folder with Claude and open the dashboard a few times a week for a
calm check-in: what needs doing next, where every application stands, what to learn.

## Product Purpose
Job Buddy is a Claude plugin that runs a person's job search from a local folder: a scoring rubric
for their field, roles found and scored 0-100 (tiers A/B/C) with evidence quoted from the ad,
honestly tailored CVs and cover letters, an application tracker, and a gap plan. Success is fewer,
better applications that convert, and a user who always knows their next step.

## Positioning
Everything stays on the user's computer by default: no Job Buddy accounts, no servers holding
CVs, no tracking. The one opt-in exception is the online dashboard, a private artifact in the
user's own Claude account holding only what the dashboard shows (roles, tiers, scores,
statuses, next actions), never the CV or notes. Every
score cites the job ad word for word, and the gap plan re-scores real roles as if a missing skill
were closed. Free, open source (MIT).

## Operating Context
The user's job-search folder holds profile.md, tracker.xlsx (the data store), seen.txt, cv/,
outputs/, jds/ and dashboard.html. Claude writes the tracker through scripts/jb.py, which
regenerates dashboard.html after every write. The dashboard is opened by double-click in any
browser or in Claude's built-in browser, offline.

## Capabilities and Constraints
- dashboard.html is one self-contained file: no network requests, no external fonts or scripts,
  all data embedded; tracker text must be escaped.
- The same page can be published once as a private Claude artifact (opt-in) that reads a
  data-only snapshot (dashboard/snapshot) from its own store; Claude updates the snapshot.
- Generated by Python (stdlib) from tracker rows and the gap report; read-only view.
- Tracker statuses: Found, Applied, Acknowledged, Assessment, Interview, Offer, Rejected, Withdrawn,
  Ghosted; Rejected At: Screening, Assessment, Interview, Final. Up to 3 tracks.

## Evidence on Hand

## Product Principles
- The user's data never leaves their computer.
- Honest over flattering: scores, gaps and tailoring never overstate.
- Always show the next step.
- Plain language for non-technical people.
